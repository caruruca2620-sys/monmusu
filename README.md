# 🌙 달빛 숲의 몬무스

몬스터 소녀(몬무스)들과 **싸우거나, 마음을 열어 친구가 되며** 달의 마녀가 있는 성으로 향하는 브라우저 로그라이트입니다.
설치할 것도, 외부 이미지도 없습니다. 캐릭터 초상화까지 전부 코드(SVG)로 그립니다.

## 플레이하기

- **한 파일 버전**: [`dist/monmusu.html`](dist/monmusu.html)을 내려받아 브라우저로 열면 바로 됩니다.
- **소스 버전**: ES 모듈을 쓰므로 로컬 서버가 필요합니다.

```bash
npx serve .
```

## 게임 소개

달빛을 잃은 숲. 등불지기인 당신은 첫 동료(슬라임 · 여우 · 맨드레이크 중 하나)와 함께 3막으로 된 숲을 지납니다.

- **싸울까, 친구가 될까**: 모든 몬무스에겐 HP ❤와 호감도 💗가 있습니다. HP가 0이면 도망치고, 호감도가 가득 차면 친구가 되어 동료로 합류합니다.
  - 💗 매혹 스킬, 등불지기의 **말 걸기**, **선물**로 호감도를 올립니다. 종족마다 좋아하는 선물은 효과가 3배.
  - 다친 몬무스일수록 마음을 잘 열지만, 공격받으면 호감도가 조금 떨어집니다.
  - 보스는 HP가 절반이 될 때까지 **마음의 벽**이 있습니다. 최종 보스와 친구가 되면 진엔딩.
- **적의 다음 행동이 보입니다**: 머리 위 말풍선으로 누구를 노리는지 미리 알고 대비하세요.
- **갈림길 지도**: 전투 · 강적 · 이벤트(15종) · 상점 · 모닥불 · 보물 중에서 길을 고릅니다.
- **부적 14종**: 파티 정원을 늘리는 왕관, 재사용 대기를 줄이는 달의 결정 등.
- **도감**: 만나고 친구가 된 몬무스는 판이 끝나도 기록됩니다 (17종).
- **오늘의 숲**: 날짜로 정해지는 일일 시드. 친구와 같은 숲을 걸어볼 수 있습니다.

## 개발

```bash
npm test          # 단위 테스트 + 자동 플레이 40판
npm run sim       # 밸런스 시뮬레이션 (기본 300판)
npm run build     # dist/monmusu.html 한 파일로 묶기
```

```
src/core/   순수 게임 로직 (DOM 없음, Node에서 그대로 테스트)
  rng.js      시드 난수 (mulberry32)
  data.js     종족 · 스킬 · 아이템 · 부적 데이터
  units.js    유닛 생성, 레벨, 능력치
  battle.js   전투 엔진 — 결과를 이벤트 배열로 돌려준다
  map.js      갈림길 지도 생성
  run.js      한 판의 진행 (보상, 영입, 상점, 막 전환)
  events.js   ❓ 이벤트들
  ai.js       자동 전투 AI (게임 내 자동 버튼 + 시뮬레이터)
src/ui/     화면
  app.js      화면 전환, 입력, 전투 연출
  portrait.js SVG 초상화 생성기 (종족 특징 + 7가지 표정)
  audio.js    WebAudio 효과음
scripts/
  build.js    의존성 없는 미니 번들러
  simulate.js 헤드리스 자동 플레이로 밸런스 측정
```

전투 엔진은 상태를 바로 바꾸고 일어난 일을 `events` 배열로 돌려줍니다. UI는 그 이벤트를 순서대로 재생하며 숫자가 떠오르고 카드가 흔들리는 연출을 합니다. 덕분에 같은 엔진을 시뮬레이터에서 화면 없이 수천 판 돌려 밸런스를 맞출 수 있습니다.

모든 캐릭터, 대사, 시스템은 이 프로젝트를 위해 새로 만든 오리지널입니다.
